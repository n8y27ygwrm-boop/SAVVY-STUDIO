VALUE RESOLVES TO SOURCE
SOURCE

A source changes.

An operator page or feed is updated. Nothing about the change announces itself, and nothing guarantees it is shaped the way it was yesterday.

INGEST

It enters under control.

The change is taken in behind a fixed ingress contract and placed on a durable queue. It is held, not yet read — in a form the system can replay later.

ELIGIBILITY

Eligibility is decided first.

Before any value is extracted, policy decides whether this source may be read. A source that fails stops here, whole, rather than partly interpreted.

EXTRACTION

Only then is the offer read.

Extraction produces a claim, not a fact. At this point the value exists and is explicitly unverified — the system says so rather than assuming otherwise.

EVIDENCE

The claim keeps its source.

The value is bound to the material it was read from. The link travels inside the record, so the claim and its evidence cannot drift apart later.

GOVERNANCE

Governance decides what leaves.

A traced value can be saved under governance. It still does not publish. Nothing publishes until it can be traced.

THE GATE

Nothing publishes until it can be traced.
